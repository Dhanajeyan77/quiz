Project Objective
Build a real-time, Kahoot-style multiplayer quiz platform optimized for 60-200 concurrent users. The platform uses a WebSocket-based backend (Python/Flask-SocketIO) and a lightweight frontend.
UI/UX Aesthetic Guidelines
Theme: Modern Dark Tech.
Styling: Deep tech black (#09090b) backgrounds, glassmorphism panels (translucent dark panels with subtle white borders and background blur), and neon accents (emerald green for success/leaderboard, electric blue for active states).
Layout: Clean, responsive grid systems. Do not use heavy UI frameworks; keep the DOM lightweight for fast WebSocket repaints.
Core System Flows
1. The Student Flow (Mobile First)
Lobby Screen: Input fields for Roll No and Full Name. A primary "Join Session" button.
Waiting Screen: A glass panel showing a loading spinner, the text "Waiting for Admin to start...", and their current Score (starts at 0).
Active Question Screen: Displays the question text, a visual 20-second countdown timer, and a 2x2 grid of buttons for the options.
Answered State: Once an option is clicked, disable all buttons and show "Answer submitted. Waiting for others..."
Final Screen: Displays "Session Complete" with their locked-in final score highlighted.
2. The Admin Dashboard Flow (Desktop Optimized)
Control Panel: Displays a live counter of "Connected Students."
Data Ingestion: An <input type="file" accept=".csv"> button to dynamically load questions (currently pre-loaded with the Default JSON below).
Game Controls: A master "Next Question" button to push the active state to all phones via WebSockets.
Live Leaderboard: A dedicated panel that updates and sorts the top scores dynamically after every question.
End & Report: A red "End Game & Save to DB" button, and a prominent purple "Download CSV Report" button to export the final Roll No, Name, and detailed answer matrix.

Scoring Logic
Base points for a correct answer: 1000.
Time deduction: Subtract points based on how long it takes the user to answer within the 15-20 second window to calculate a speed bonus.
